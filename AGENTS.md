#Kanban Project

##Business Requirements

1. An MVP of a Kanban style Project Management application as a web app
2. The webapp should only have 1 board
3. The board has fixed 5 columns that can be renamed
4. Each card has a title and details only
5. Drag and drop interface to move cards between columns
6. Add a new card to column, delete an existing card
7. No more functionality; no archive , no search / filter. keep it simple
8. The priority is aslick, professional gorgeous UI/UX with very simple features
9. The app should open with dummy data populated for the single board

##Technical details

1. Implemented as a modern ReactJS app using vite, client rendered
2. The ReactJS app should be created in a subdirectory called frontend
3. No persistence
4. No user Management for the MVP
5. Use popular libraries
6. As simple as possible but with an elegant UI

##Color Scheme

1. Primary Green #097969 - accents lines , highlights
2. Accent White #E6FFE6 - links, key sections

##Strategy

1. Write a plan with success criteria for each phase to be checked off. Include project scaffolding, including .gitignore, and rigorous unit testing.
2. Execute the plan ensuring all criteria are met
3. Carry out extensive integration testing with playwright or similar fixing defects
4. Only complete when MVP is finished and tested, with server running and ready for user

##Coding Standards

1. Use latest versions of libraries and idiomatic approaches as of today
2. Keep it simple - never over engineer, always simplify, no unnecessary defensive programming. No extra features- focus on simplicity
3. Be concise, keep README minimal. IMPORTANT: no emojis ever
